What is Python?

Python is a popular, easy-to-learn programming language.

  • It uses simple, English-like commands.
  • It's versatile: used for websites, games, AI, and more!
  • It's like a universal translator for talking to computers.
Analogy: Think of Python as a friendly robot. You give it simple, clear instructions in a language you both understand, and it performs tasks for you. 🤖

Hello, World!

Let's write our first instruction: making the computer say "Hello, World!".

print("Hello, World!")

The `print()` function is like telling your robot friend to speak. Whatever you put inside the parentheses and quotes, it will display on the screen.

Another Example

print("Python is fun!")
print(123)

Variables: Storing Information

In programming, we need places to store information. These are called variables.

student_name = "Alex"
age = 15
print(student_name)
print(age)
Analogy: Variables are like labeled boxes. You can put something inside the box (like text or a number) and give it a name (the label). When you need the information, you just use the label! 📦

Another Example

favorite_subject = "Science"
number_of_pets = 2
print("My favorite subject is", favorite_subject)

Data Types: What's in the Box?

Variables can hold different types of data.

  • String (`str`): Plain text. Always inside quotes. "Hello"
  • Integer (`int`): Whole numbers. 10, -5, 101
  • Float (`float`): Numbers with decimals. 3.14, 99.9

Checking a Type

You can use the `type()` function to see what kind of data is in a variable.

message = "Hi there!"
print(type(message)) # This will show
Analogy: Think of data types like different kinds of snacks. A string is like a sentence on a fruit roll-up. An integer is a whole apple 🍎, and a float is a sliced apple 🍏.

Getting User Input

You can make your programs interactive by asking the user for information with the `input()` function.

# Ask the user for their name
name = input("What's your name? ")

# Say hello to the user
print("Hello, " + name + "!")
Analogy: `input()` is like asking a friend a question and waiting for them to text you back. Your program waits for their reply before it continues.

Let's Do Some Math!

Python can work as a powerful calculator.

a = 10
b = 5

sum = a + b         # Addition -> 15
difference = a - b  # Subtraction -> 5
product = a * b     # Multiplication -> 50
quotient = a / b    # Division -> 2.0

Another Example

# Order of operations (PEMDAS) applies!
result = 5 + 2 * 3  # 2*3 is done first, so result is 11

# Using parentheses
result_2 = (5 + 2) * 3 # 5+2 is done first, so result is 21

Booleans: True or False?

A boolean is a data type that can only have one of two values: `True` or `False`.

These are crucial for making decisions in your code.

is_raining = True
is_sunny = False
Analogy: A boolean is like a light switch. It can only be ON (`True`) or OFF (`False`). There's no in-between. 💡

Making Comparisons

We can compare values, and the result is always a boolean (`True` or `False`).

Operators

  • `==` : Is equal to?
  • `!=` : Is not equal to?
  • `>` : Is greater than?
  • `<` : Is less than?
  • `>=` : Is greater than or equal to?
  • `<=` : Is less than or equal to?

Comparing in Action

age = 16
print(age > 13)  # This will print: True

my_grade = 95
print(my_grade == 100) # This will print: False

Control Flow: `if` Statements

An `if` statement runs a block of code only if a certain condition is `True`.

age = 18
if age >= 18:
    print("You are old enough to vote!")
Analogy: An `if` statement is like a fork in the road with a sign. If the sign says "Road Open" (`True`), you go down that path. If not, you just continue on the main road.

Your Turn! 🚀

The `else` Statement: Plan B

The `else` statement lets you provide an alternative block of code to run if the `if` condition is `False`.

age = 15
if age >= 18:
    print("You can vote!")
else:
    print("You are not old enough to vote yet.")
Analogy: You're at a vending machine. IF you have enough money, you buy a snack. ELSE (if you don't), you walk away hungry.

Your Turn! 🚀

`elif`: Multiple Choices

`elif` stands for "else if". It lets you check for multiple conditions in a sequence.

score = 85
if score >= 90:
    print("Grade: A")
elif score >= 80:
    print("Grade: B")
elif score >= 70:
    print("Grade: C")
else:
    print("Grade: F")

Python runs the code for the *first* condition that is `True`.
